# 🍽️ بوت حساب الوجبات والسعرات (بدون ذكاء اصطناعي)

بوت تليكرام يذكرك تاكل كل ٣ ساعات، وتدزله السعرات والبروتين يدويا لكل وجبة،
ويعطيك ملخص بنهاية اليوم يكولك حققت هدفك بالسعرات والبروتين لو لا.

## شلون يشتغل

1. `/start` — تسجل بياناتك أول مرة (الجنس، الوزن، الطول، العمر، مستوى النشاط)، والبوت يحسبلك:
   - هدف السعرات اليومي (فائض 500 سعرة لأجل زيادة وزن صحية)
   - هدف البروتين اليومي (1.8 غرام لكل كيلوغرام من وزنك — لدعم بناء العضلات)
2. كل 3 ساعات (9، 12، 3، 6، 9 مساءا بتوقيت بغداد) يوصلك تذكير تاكل وجبة.
3. بعد ما تاكل، بس ادزلي رقمين بنفس الرسالة: **السعرات ثم البروتين** (مثلا: `600 35`).
4. لو الرقم غلط، **رد (Reply) على رسالة تأكيد البوت بالذات** بالأرقام الصحيحة وبيعدلها.
5. الساعة 11:30 بالليل يوصلك ملخص كامل: كم وجبة، مجموع السعرات والبروتين، وهل حققت هدفك.
6. `/today` لملخص فوري، `/reset` لتعديل بياناتك.

## المتطلبات

- توكن بوت تليكرام بس (من [@BotFather](https://t.me/BotFather)) — **ماكو حاجة لأي مفتاح AI أو خدمة خارجية**، البوت يشتغل بالكامل محليا بدون انترنت خارجي غير تليكرام نفسه.

## التشغيل على Railway

1. سوي حساب على [railway.app](https://railway.app) وسجل دخول بحساب GitHub
2. اضغط "New Project" → "Deploy from GitHub repo" واختار مستودعك
3. من تبويب "Variables" ضيف بس: `BOT_TOKEN` = توكن البوت مالك
4. Railway يسوي Deploy تلقائي — تابع اللوگز (Logs) وتأكد يطبع "البوت اشتغل ✅"

## التشغيل محليا (لو عندك كمبيوتر)

```bash
pip install -r requirements.txt
cp .env.example .env
# افتح .env وحط توكن البوت مالك
python bot.py
```

## هيكلية المشروع

```
meal-calorie-bot/
├── bot.py              # نقطة تشغيل البوت الرئيسية
├── config.py           # الإعدادات (التوكن، أوكات التذكير)
├── database.py         # قاعدة بيانات SQLite (المستخدمين والوجبات)
├── nutrition.py        # معادلات حساب هدف السعرات والبروتين
├── handlers.py         # محادثة التسجيل + تسجيل/تعديل الوجبات + الأوامر
├── scheduler.py        # التذكيرات الدورية وملخص نهاية اليوم
├── requirements.txt
└── .env.example
```

## ملاحظات مهمة

- هذا الإصدار **يدوي بالكامل** — أنت تدخل السعرات والبروتين لكل وجبة بنفسك (مثلا من تطبيق حساب سعرات ثاني أو من خبرتك)، البوت بس يجمعها ويقارنها بهدفك اليومي.
- أوكات التذكير (`REMINDER_HOURS`) وساعة الملخص (`DAILY_SUMMARY_HOUR`) تكدر تعدلها من `config.py`.
- هدف البروتين محسوب بمعدل 1.8 غ/كغم — تكدر تغيره من دالة `calculate_protein_target` بملف `nutrition.py`.
- الفائض الحراري لزيادة الوزن محدد بـ 500 سعرة/يوم افتراضيا — تكدر تغيره من `CALORIE_SURPLUS_FOR_GAIN` بملف `config.py`.
