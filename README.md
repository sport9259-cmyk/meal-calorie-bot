# 🍽️ بوت حساب الوجبات والسعرات الحرارية

بوت تليكرام يذكرك تاكل كل ٣ ساعات، ويحسب سعرات وجبتك من صورتها تلقائيا باستخدام الذكاء الصناعي، ويعطيك ملخص بنهاية اليوم بيكولك حققت هدفك بالسعرات لو لا.

## شلون يشتغل

1. `/start` — تسجل بياناتك أول مرة (الجنس، الوزن، الطول، العمر، مستوى النشاط)، والبوت يحسبلك رينج السعرات المطلوب يوميا لأجل تزيد وزن بشكل صحي (فيه فائض 500 سعرة عن حاجتك الطبيعية).
2. كل 3 ساعات (الساعة 9، 12، 3، 6، 9 مساءا بتوقيت بغداد) يوصلك تذكير تاكل وجبة.
3. بعد ما تاكل، بس اكتبلي شنو اكلت (مثلا: "صحن تمن مع لبن") — راح احللها ويطلعلك وصف تقريبي وعدد السعرات. لو الرقم غلط، رد (Reply) على رسالة التأكيد بالتصحيح.
4. الساعة 11:30 بالليل يوصلك ملخص كامل: كم وجبة اكلت، مجموع السعرات، وهل حققت هدفك اليومي لو لا.
5. `/today` — تكدر تشوف ملخص اليوم بأي وكت.
6. `/reset` — تعدل بياناتك (وزن جديد، الخ) وياخذ رينج جديد.

## المتطلبات

- توكن بوت تليكرام (تحصل عليه من [@BotFather](https://t.me/BotFather))
- مفتاح OpenRouter API **مجاني** (من [openrouter.ai/keys](https://openrouter.ai/keys)) — يستخدم لتحليل صور الوجبات وحساب السعرات. التسجيل بس بايميل أو حساب GitHub، بدون بطاقة ائتمان.

## التشغيل على Replit (أسهل طريقة، ماكو حاجة لجهاز كمبيوتر)

1. اسوي حساب على [replit.com](https://replit.com) (تكدر تفتحه من المتصفح بالآيباد).
2. اضغط "Create Repl" واختار "Import from GitHub" أو "Upload folder" ورفع هذا المجلد كامل.
3. أو انسخ كل ملف بالمشروع لصفحة جديدة بـ Replit (بيئة Python).
4. من تبويب "Secrets" (🔒) بـ Replit ضيف:
   - `BOT_TOKEN` = توكن البوت مالك
   - `OPENROUTER_API_KEY` = مفتاح OpenRouter مالك (مجاني)
5. افتح "Shell" واكتب: `pip install -r requirements.txt`
6. اضغط زر "Run" — البوت راح يشتغل.
7. علمود يضل شغال 24/7 حتى لو سكرت المتصفح، فعّل خاصية "Always On" أو اربطه بخدمة مثل UptimeRobot تسوي ping له كل شوي (Replit المجاني ينام الاستضافة اذا ماكو زيارات).

## التشغيل على Railway

Railway أفضل من Replit للتشغيل المستمر 24/7 لأنه ماكو مشكلة "نوم" الاستضافة، بس تحتاج تربط بطاقة (فيه باقة مجانية محدودة بالساعات/الدولارات شهريا).

1. اسوي حساب على [railway.app](https://railway.app) (تكدر من المتصفح بالآيباد) وتربطه مع GitHub.
2. ارفع هذا المجلد لمستودع (repo) جديد على GitHub — أسهل طريقة من الآيباد: تفتح [github.com](https://github.com) وتسوي repo جديد وتستخدم "Upload files" وتسحب كل الملفات إلها.
3. من Railway اضغط "New Project" → "Deploy from GitHub repo" واختار الـ repo.
4. من تبويب "Variables" ضيف:
   - `BOT_TOKEN` = توكن البوت مالك
   - `OPENROUTER_API_KEY` = مفتاح OpenRouter مالك (مجاني)
5. Railway يحتاج يعرف شلون يشغل المشروع؛ ضيف بالمستودع ملف اسمه `Procfile` (بدون امتداد) بهذا المحتوى:
   ```
   worker: python bot.py
   ```
6. Railway راح يكتشف تلقائيا انه مشروع Python ويسوي `pip install -r requirements.txt` ويشغل الـ worker. لو ما اشتغل تلقائي، من "Settings" حدد "Start Command" = `python bot.py`.
7. تابع اللوگز (Logs) من صفحة المشروع تتأكد يطبع "البوت اشتغل ✅".

**ملاحظة:** لا تشغل نفس البوت (نفس BOT_TOKEN) بمكانين بنفس الوكت (Replit و Railway سوا) — تليكرام يرفض ويصير تضارب. اختار وحدة تشتغل عليها فعليا، والثانية خليها احتياط لو الأولى وكفت.

## التشغيل محليا (لو عندك كمبيوتر)

```bash
pip install -r requirements.txt
cp .env.example .env
# افتح .env وحط التوكنات مالتك
python bot.py
```

## هيكلية المشروع

```
meal-calorie-bot/
├── bot.py                 # نقطة تشغيل البوت الرئيسية
├── config.py              # الإعدادات (التوكنات، أوكات التذكير)
├── database.py            # قاعدة بيانات SQLite (المستخدمين والوجبات)
├── nutrition.py           # معادلة حساب السعرات المطلوبة (Mifflin-St Jeor)
├── calorie_estimator.py   # تحليل صور الوجبات عبر OpenRouter (مجاني)
├── handlers.py            # محادثة التسجيل + استقبال الصور + الأوامر
├── scheduler.py           # التذكيرات الدورية وملخص نهاية اليوم
├── requirements.txt
└── .env.example
```

## ملاحظات مهمة

- تقدير السعرات من الوصف النصي **تقريبي** ويعتمد على وضوح الوصف الي تكتبه — مو بديل عن استشارة أخصائي تغذية لو عندك حالة صحية معينة.
- أوكات التذكير (`REMINDER_HOURS`) وساعة الملخص (`DAILY_SUMMARY_HOUR`) تكدر تعدلها من `config.py`.
- الفائض الحراري لزيادة الوزن محدد بـ 500 سعرة/يوم بشكل افتراضي (معدل آمن للزيادة التدريجية) — تكدر تغيره من `CALORIE_SURPLUS_FOR_GAIN` بملف `config.py`.
